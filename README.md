## 실행 방법

```bash
npm install
npm run dev
```

- 검증은 `npm test`, 배포용 빌드는 `npm run build`로 실행합니다.
- Windows PowerShell 실행 정책으로 `npm`을 실행할 수 없는 경우 `npm.cmd`를 사용합니다.
